# SIEM Nimbus

## Live demo
[SIEM Nimbus Live Demo](https://siem-nimbus.vercel.app/)

## Project Description
SIEM Nimbus is a comprehensive Security Information and Event Management (SIEM) solution designed to provide real-time monitoring, threat detection, and incident response capabilities. It integrates various security tools and data sources to offer a unified view of an organization's security posture.

## Features
- **Dashboard**: Centralized dashboard for an overview of security metrics and system health.
- **Alerts Management**: Real-time alerts and incident management.
- **Logs Management**: Collection, analysis, and storage of logs from various sources.
- **Network Scanner**: Discover devices and identify vulnerabilities in the network.
- **Malware Detector**: Detect and mitigate malware threats.
- **Vulnerability Checker**: Identify and assess system vulnerabilities.
- **Data Collector**: Collect and process security-related data.
- **User Management**: Manage user accounts and roles within the system.
- **Reporting**: Generate comprehensive security reports.

## Installation

To set up the project locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/abdullahdigital/siem-nimbus
   cd siem-nimbus
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```
   The application will be accessible at `http://localhost:5174`.

## Usage

After starting the application, navigate to the dashboard to view security metrics. You can explore different sections like Alerts, Logs, Network Scanner, etc., using the sidebar navigation.
